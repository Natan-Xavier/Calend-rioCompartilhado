# 📅 Calendário Compartilhado (Shared Calendar)

Um sistema de calendário compartilhado construído com **Python**. Este projeto possui uma arquitetura dividida em um Back-end de API RESTful utilizando **Flask** e um Front-end desktop desenvolvido com **PyQt**. 

## 🚀 Funcionalidades (Endpoints da API)

O servidor Flask expõe os seguintes endpoints para gerenciamento do calendário:

* `POST /usuarios` - Criação de um novo usuário.
* `POST /eventos` - Criação de um novo evento no calendário.
* `POST /lembretes` - Criação de um novo lembrete.
* `POST /tarefas` - Adição de uma nova tarefa.
* `GET /tarefas` - Visualização de todas as tarefas cadastradas.
* `DELETE /tarefas/<id>` - Exclusão de uma tarefa específica.

## 🛠️ Tecnologias e Ferramentas

* **Linguagem:** Python 3.13
* **Back-end:** Flask (API REST)
* **Front-end:** PyQt (Interface Gráfica Desktop)
* **Design Patterns:** [Singleton, Observer, Command, Proxy]
